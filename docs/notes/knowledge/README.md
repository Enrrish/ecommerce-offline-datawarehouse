## 怎么用

1. 先读 [`01_数仓分层与SQL思维.md`](01_数仓分层与SQL思维.md)，把"每一层在消灭什么不确定性"刻进脑子；

3. 每章末尾有自测题，**先合上文档口述，再对照**；能讲清楚才算会；
4. 忘了某个语法，直接在本目录搜关键词，不用翻项目 SQL。

## 一条主线

```mermaid
flowchart LR
    A["原始日志<br/>不可信、不可直接算"] --> B["ODS<br/>原样 + 可回溯"]
    B --> C["DWD<br/>一条行为的唯一定义"]
    C --> D["DWS<br/>主题粒度 + 业务口径"]
    D --> E["ADS<br/>看板要什么就有什么"]
    E --> F["报表 / 看板"]
    C -.-> G["维表<br/>跨天共享的稳定属性"]
    G -.-> D
```

一句话概括四层：

> **ODS 保存事实，DWD 定义事实，DWS 解释事实，ADS 呈现事实。**
